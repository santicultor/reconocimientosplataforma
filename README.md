# Conexión · Reconocimientos DBEE

Plataforma mensual de reconocimiento entre compañeros (DBEE · Universidad de La Sabana).
Guía completa en [GUIA.md](./GUIA.md).

- `npm run dev:demo` — modo demostración, sin base de datos.
- `npm run dev` — modo real (requiere variables de `.env.example`).
- `npm test` — pruebas de las reglas del ciclo.
